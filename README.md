# Tracker

Трекер привычек для iPhone. Учебный проект курса iOS-разработки Яндекс Практикума.

Задание: [iOS-TrackerApp-Public](https://github.com/Yandex-Practicum/iOS-TrackerApp-Public). Макет: [Figma](https://www.figma.com/design/owAO4CAPTJdpM1BZU5JHv7/Tracker).

## Назначение

Приложение помогает формировать полезные привычки и следить за их выполнением.

Цели:

- контролировать привычки по дням недели;
- смотреть прогресс по привычкам.

## Краткое описание

Пользователь создаёт карточки-трекеры. У карточки есть название, категория и расписание, а ещё эмодзи и цвет, чтобы отличать карточки друг от друга.

Карточки собраны по категориям. Их можно искать и фильтровать.

В календаре видно, какие привычки запланированы на выбранный день.

Статистика показывает успешные показатели, прогресс и средние значения.

## Что умеет приложение

Привычка повторяется по выбранным дням недели. Нерегулярное событие к дням не привязано.

На главном экране карточки собраны по категориям. Их можно искать по названию, фильтровать и смотреть на выбранный день в календаре. Карточку можно закрепить, изменить или удалить.

Во вкладке «Статистика» четыре показателя:

- лучший период — самая длинная серия дней без перерыва;
- идеальные дни — дни, когда выполнены все запланированные привычки;
- трекеров завершено — сколько раз привычки были отмечены;
- среднее значение — сколько привычек выполняется за день.

При первом запуске показывается онбординг. Тёмная тема следует настройке системы.

## Стек

UIKit, Core Data, iOS 17. Есть аналитика AppMetrica, локализация и snapshot-тесты.

## Запуск

```bash
git clone https://github.com/dpogonia/Tracker-YANDEX.git
cd Tracker-YANDEX
open Tracker.xcodeproj
```

Запустите схему **Tracker** на симуляторе iPhone с iOS 17.
